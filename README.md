# Happy Birthday ✨ Digital Photobooth

A single-page "digital birthday experience" built with React + Vite + Tailwind CSS.
Everything runs fully in the browser — no backend, no server-side processing.
Camera capture, photo compositing, and PNG export all happen on the client with
the Canvas API.

## Getting started

```bash
npm install
npm run dev       # local dev server
npm run build     # production build → dist/
npm run preview   # preview the production build
```

The camera (`getUserMedia`) requires either `localhost` or HTTPS to work in the
browser — this is a browser security rule, not a bug in the app.

## What to edit first

**`src/config/site.js`** — this is the one file you'll want to open first:
- `recipientName` — shown in the Hero, the Wish card, and stamped on the final photostrip
- `heroTagline`, `heroButtonLabel`
- `memories` — array of `{ image, caption }`, swap in your own photos
- `wishQuote`, `wishMessage` — the birthday card text
- `FRAMES` — the list of selectable frames (see below)

## Replacing the photo frames

Three dummy frames are included in `public/assets/frames/`:

- `frame-gold-elegance.png`
- `frame-pink-blossom.png`
- `frame-ivory-classic.png`

They're transparent PNGs at **1080 × 1920px** with a decorative border and a
transparent center (so the 3 photos show through). To use your own frame:

1. Design your frame at 1080×1920 with a transparent middle.
2. Drop the PNG into `public/assets/frames/`.
3. Add/replace an entry in the `FRAMES` array in `src/config/site.js`:

```js
{ id: "my-frame", name: "My Frame", src: "/assets/frames/my-frame.png" }
```

(The 3 placeholder frames were generated by `scripts/make_frames.py` if you want
to regenerate or tweak them programmatically instead of designing by hand.)

## Replacing the memory photos

Swap the files in `public/assets/images/` with your own, and update the
`memories` array in `src/config/site.js` to point at them.

## Project structure

```
src/
  components/
    Navbar.jsx        — transparent glass navbar, scroll + mobile state
    Hero.jsx           — landing section with floating decorations
    Memories.jsx       — scrapbook-style photo grid
    WishCard.jsx       — glass card with quote + typed-in message
    Camera.jsx         — live getUserMedia video + capture button/flash
    CaptureStep.jsx    — single step: live camera → Retake / Use This Photo
    Preview.jsx        — 3-photo strip + per-photo Edit buttons
    FrameSelector.jsx  — frame picker with live preview
    Photobooth.jsx      — orchestrates the whole capture → frame → download flow
    Gallery.jsx        — masonry gallery of past downloads (persisted to localStorage)
    Footer.jsx
    Decorations.jsx    — ambient sparkles/flowers
    Reveal.jsx         — scroll-reveal wrapper
  hooks/
    useCamera.js       — getUserMedia lifecycle + frame capture
    useOnScreen.js      — IntersectionObserver hook for scroll reveals
    useTypedText.js    — typewriter-style text reveal
  utils/
    mergeCanvas.js     — composites photos + frame + date/name into final PNG
    download.js        — triggers the browser download with a timestamped filename
  config/
    site.js            — all editable content lives here
```

## Notes

- The final export downloads as `Birthday_Photobooth_YYYYMMDD_HHMMSS.png`.
- Each completed photobooth session is also saved into the on-page Gallery
  (stored in the browser's `localStorage`, so it persists across reloads on
  the same device/browser — it isn't uploaded anywhere).
- Motion respects `prefers-reduced-motion`.
